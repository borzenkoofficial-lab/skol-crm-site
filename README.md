# СКОЛ CRM — cinematic website

Самостоятельный сайт СКОЛ CRM. Работа ведётся в ветке feat/mclaren-inspired-cinematic-experience; production и другие репозитории не затрагиваются.

## Motion direction

Кинематографический пролёт через цифровую модель строительного объекта: данные сходятся в систему, раскрывается конструктив здания, камера переходит к экономике и заканчивает маршрут единым контуром управления.

## Runtime

- Three.js r187 / WebGL — процедурная архитектурная сцена, пятиуровневый строительный каркас, башенный кран, стеклянный фасад, финансовая геометрия, 3D-карточки данных, свет и частицы. Частицы morph-ятся по scroll progress через четыре формы: входящие данные, конструктив объекта, экономическая модель и центральный контур управления.
- GSAP 3.15.1 + ScrollTrigger — скролл управляет камерной траекторией и четырьмя главами.
- Камера проходит семь режиссёрских beats по Catmull–Rom spline: общий план входящих данных, близкий проход по конструктиву, скольжение вдоль фасада, крупный план экономики, орбитальный проход вокруг ядра и финальный отъезд. Точка взгляда проходит отдельную синхронную траекторию.
- Сцены собираются и растворяются по собственным кривым видимости; типографика входит синхронно с главами. Наклон камеры задаётся абсолютным значением от scroll progress, без накопления ошибки между кадрами.
- Мобильный pixel ratio, отключение рендера вне видимой сцены и reduced-motion fallback.

## Ограничения

Геометрия процедурная и служит визуальной метафорой. Это не модель конкретного объекта СКОЛ и не скриншот реального CRM. Для продуктовой достоверности понадобятся реальные экраны программы и согласованный визуальный материал.
