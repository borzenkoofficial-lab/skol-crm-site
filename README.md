# СКОЛ CRM — cinematic website

Новая самостоятельная версия сайта СКОЛ CRM. Разработка ведётся в ветке `feat/mclaren-inspired-cinematic-experience`; production и другие репозитории не затрагиваются.

## Запуск
Это статический сайт без сборщика:
- откройте `index.html` локально или запустите любой static server;
- для Vercel используйте корень репозитория как Output Directory.

## Реализованные элементы
- кинематографический hero с CSS-визуализацией интерфейса;
- scroll reveal через IntersectionObserver;
- параллакс и магнитные интерактивные элементы;
- прогресс прокрутки и анимированная линия этапов;
- адаптивная мобильная композиция;
- поддержка prefers-reduced-motion.
