# СКОЛ CRM — cinematic website

Новая самостоятельная версия сайта СКОЛ CRM. Разработка ведётся в ветке `feat/mclaren-inspired-cinematic-experience`; production и другие репозитории не затрагиваются.

## Запуск

Это статический сайт:
- откройте `index.html` через любой static server;
- Vercel использует корень репозитория как Output Directory;
- для 3D-сцены браузеру требуется WebGL и доступ к CDN.

## Motion stack

- Three.js r187 — процедурная WebGL-сцена с реальной перспективной камерой, 3D-геометрией, светом, частицами и пространственными слоями;
- GSAP 3.15.1 + ScrollTrigger — скролл как scrub-контроллер общей временной шкалы;
- камера перемещается между четырьмя режиссёрскими состояниями;
- данные, структура объекта, экономика и единый контроль имеют собственные визуальные группы, которые собираются и растворяются при прокрутке;
- движение камеры и световых элементов реагирует на позицию скролла и указатель;
- есть мобильный режим, ограничение pixel ratio, пауза рендера вне видимой сцены и reduced-motion fallback.

## Важно

3D-сцена процедурная и создана из геометрии Three.js. Это не готовая видеопоследовательность и не финальная модель реального интерфейса CRM. Для следующего уровня реализма понадобятся проверенные скриншоты СКОЛ CRM и специально подготовленные визуальные ассеты. Контакт для демонстрации пока не задан — адреса не выдумываются.

## Проверки

`npm test` и `npm run check:js` проверяют структуру страницы, наличие WebGL/ScrollTrigger, reduced-motion fallback и синтаксис JavaScript.
